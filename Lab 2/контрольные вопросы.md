1. Что представляет собой переменная в Python?
Переменная — это имя, которое используется для хранения определённого значения в памяти программы. Например: x = 10.

2. Какие основные типы данных используются в Python?
Основные типы данных: int — целые числа, float — дробные числа, str — строки, bool — логические значения (True и False).

3. Чем int отличается от float?
int используется для целых чисел, например 10, -5, 100. float используется для чисел с дробной частью, например 10.5, 3.14.

4. Как работает функция input()?
input() позволяет получить данные, введённые пользователем с клавиатуры.

5. Почему результат input() часто необходимо преобразовывать?
Потому что input() возвращает введённое значение в виде строки (str), даже если пользователь вводит число. Для выполнения математических операций строку необходимо преобразовать в число.

6. Для чего используются int() и float()?
int() преобразует значение в целое число, а float() — в число с плавающей точкой (дробное число).

7. Чем / отличается от //?
/ выполняет обычное деление и возвращает результат, в том числе с дробной частью. // выполняет целочисленное деление, возвращая результат без дробной части.

8. Что делает оператор %?
Оператор % возвращает остаток от деления.

9. Для чего используется оператор **?
Оператор ** используется для возведения числа в степень.

10. Как определить тип переменной с помощью type()?
С помощью функции type()

11. Что такое преобразование типов?
Преобразование типов — это изменение типа данных одного значения в другой.

12. Что произойдёт при попытке int("Python")?
Возникнет ошибка ValueError, потому что строку "Python" невозможно преобразовать в целое число.

13. Как получить последнюю цифру целого числа?
С помощью оператора %

14. Как удалить последнюю цифру целого числа?
С помощью целочисленного деления // на 10

15. Почему выбор правильного типа данных важен?
Правильный тип данных позволяет корректно хранить и обрабатывать информацию, выполнять необходимые операции и избегать ошибок в программе. Например, для вычислений с дробными числами следует использовать float
