# Планировщик учебных задач

Учебный мини-проект для планирования и контроля выполнения заданий студентом.

Приложение позволяет создавать учебные задачи, указывать предмет, срок выполнения, приоритет и статус, а также искать, фильтровать, редактировать и удалять задачи.

## Цель проекта

Цель проекта — разработать простой и понятный инструмент, который помогает студенту организовать учебные задания и контролировать сроки их выполнения.

## Проблема

Во время обучения студент одновременно получает задания по нескольким дисциплинам. Большое количество заданий усложняет контроль сроков и может привести к пропуску дедлайнов.

Планировщик позволяет хранить информацию о заданиях в одном месте и отслеживать процесс их выполнения.

## Целевая аудитория

Основная целевая аудитория — студенты колледжей и университетов.

## Возможности

Приложение позволяет:

- создавать учебные задачи;
- указывать предмет;
- устанавливать срок выполнения;
- выбирать приоритет;
- устанавливать статус задачи;
- редактировать задачи;
- удалять задачи;
- отмечать задачи выполненными;
- искать задачи по названию и предмету;
- фильтровать задачи по статусу и приоритету;
- автоматически определять просроченные задачи;
- просматривать статистику;
- сохранять задачи после перезагрузки страницы.

## Используемые технологии

Проект разработан с использованием:

- HTML5 — структура интерфейса;
- CSS3 — оформление;
- JavaScript — логика приложения;
- Local Storage — локальное хранение задач.

Сервер и отдельная база данных не требуются.

## Запуск проекта

Для запуска не требуется установка дополнительных библиотек.

1. Скачать или клонировать репозиторий.
2. Открыть папку `study-planner`.
3. Открыть файл `index.html` в современном браузере.

Приложение запускается локально и не требует подключения к серверу.

## Пример использования

1. Нажать кнопку «Новая задача».
2. Ввести название задания.
3. Указать учебный предмет.
4. Выбрать срок выполнения.
5. Установить приоритет.
6. Выбрать статус.
7. Нажать «Сохранить».

После сохранения задача появится в общем списке.

Задачу можно изменить, удалить или отметить выполненной.

## Хранение данных

Данные хранятся в Local Storage браузера.

Задачи представлены в JavaScript в виде массива объектов.

Пример:

```javascript
{
    id: 1,
    title: "Подготовить презентацию",
    subject: "Программирование",
    deadline: "2026-10-22",
    priority: "Высокий",
    status: "В процессе"
}
```

После изменения массива информация сохраняется с помощью:

```javascript
localStorage.setItem("studyTasks", JSON.stringify(tasks));
```

При повторном открытии приложения данные загружаются из Local Storage.

## Архитектура

Приложение состоит из трёх основных частей:

- HTML — пользовательский интерфейс;
- CSS — визуальное оформление;
- JavaScript — обработка данных и логика программы.

Основная структура данных — массив `tasks`.

Для работы с массивом используются функции, циклы, условия, поиск, фильтрация и сортировка.

Подробнее архитектура описана в `docs/design.md`.

## Аналоги

Перед разработкой были рассмотрены:

- Microsoft To Do;
- Google Tasks.

В отличие от универсальных систем управления задачами, данный проект ориентирован на простой учёт учебных заданий студента.

Подробный анализ находится в `docs/analysis.md`.

## Тестирование

Для приложения подготовлено 8 тест-кейсов:

- 4 основных сценария;
- 2 теста ошибочного ввода;
- 2 граничных случая.

Проверяются создание, редактирование, выполнение и удаление задач, обработка неправильного ввода, поиск и определение просроченных заданий.

Результаты находятся в:

`tests/test_cases.md`

## Ограничения

Текущая версия имеет следующие ограничения:

- данные сохраняются только в браузере пользователя;
- отсутствует синхронизация между устройствами;
- отсутствует регистрация;
- отсутствуют уведомления;
- приложение предназначено для индивидуального использования.
