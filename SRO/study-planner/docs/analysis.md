# Анализ предметной области

## 1. Название проекта

Планировщик учебных задач.

## 2. Предметная область

Проект относится к сфере образования и организации учебного процесса.

Студенты одновременно выполняют задания по нескольким дисциплинам: практические работы, СРО, домашние задания, презентации и другие виды работ. Каждая задача имеет свой срок выполнения и разную степень важности.

При большом количестве заданий студенту становится сложнее контролировать сроки и определять, какие задачи необходимо выполнить в первую очередь.

## 3. Проблема

Основная проблема — необходимость хранить информацию о большом количестве учебных заданий и контролировать сроки их выполнения.

Без использования планировщика студент может:

- забыть о задании;
- пропустить срок сдачи;
- потерять информацию о задаче;
- неправильно распределить учебную нагрузку;
- не понимать, какие задания уже выполнены.

Поэтому требуется простой инструмент, позволяющий хранить учебные задачи в одном месте и контролировать их выполнение.

## 4. Целевая аудитория

Основной целевой аудиторией являются студенты колледжей и университетов.

Приложение может использоваться студентами, которым необходимо:

- записывать учебные задания;
- указывать предмет;
- устанавливать срок выполнения;
- определять приоритет задачи;
- отслеживать статус выполнения;
- быстро находить необходимые задания.

## 5. Анализ существующих решений

Перед разработкой проекта были рассмотрены существующие приложения для управления задачами.

### Todoist

Todoist — сервис для создания и организации задач.

Основные возможности:

- создание задач;
- установка сроков;
- использование приоритетов;
- создание проектов;
- фильтрация задач;
- синхронизация между устройствами.

Преимущества:

- большое количество функций;
- удобный интерфейс;
- возможность организации сложных проектов.

Недостатки:

- часть возможностей доступна только в платных тарифах;
- для простого ведения учебных заданий некоторые функции являются избыточными.

### Microsoft To Do

Microsoft To Do — приложение для создания списков задач.

Основные возможности:

- создание задач;
- установка сроков;
- напоминания;
- создание отдельных списков;
- отметка выполненных задач.

Преимущества:

- простой интерфейс;
- бесплатное использование;
- синхронизация с учетной записью Microsoft.

Недостатки:

- приложение не ориентировано специально на учебные задачи;
- для использования синхронизации требуется учетная запись.

### Google Tasks

Google Tasks — сервис управления задачами, интегрированный с сервисами Google.

Основные возможности:

- создание задач;
- установка даты;
- создание списков;
- отметка выполненных задач;
- интеграция с Google Calendar.

Преимущества:

- простой интерфейс;
- интеграция с другими сервисами Google;
- доступ с разных устройств.

Недостатки:

- ограниченные возможности работы с приоритетами;
- приложение предназначено для общих задач, а не специально для организации учебного процесса.

## 7. Разрабатываемое решение

Разрабатываемое приложение представляет собой простой планировщик, ориентированный на учебные задачи студентов.

Пользователь может создать задачу и указать:

- название;
- учебный предмет;
- срок выполнения;
- приоритет;
- текущий статус.

Приложение также позволяет редактировать и удалять задачи, отмечать их выполненными, искать необходимые задания и использовать фильтрацию.

Для хранения данных используется Local Storage браузера. Благодаря этому задачи сохраняются после обновления или закрытия страницы и не требуют отдельной базы данных или сервера.

## 8. Ограничения проекта

Разрабатываемая версия имеет следующие ограничения:

- данные хранятся только в браузере пользователя;
- отсутствует синхронизация между устройствами;
- отсутствует регистрация пользователей;
- отсутствуют уведомления о приближении срока;
- приложение рассчитано преимущественно на индивидуальное использование.

Для учебного мини-проекта данные ограничения являются допустимыми и позволяют сосредоточиться на основных функциях планирования задач.

## 9. Актуальность проекта

Планирование времени является важной частью учебного процесса. Студенту необходимо одновременно контролировать задания по различным дисциплинам и соблюдать сроки их выполнения.

Планировщик позволяет собрать информацию о заданиях в одном месте, определить наиболее важные задачи и отслеживать процесс их выполнения.

Таким образом, разработка простого планировщика учебных задач является актуальной задачей и может помочь студентам эффективнее организовывать учебную деятельность.

## 10. Вывод

В результате анализа предметной области было установлено, что существуют различные системы управления задачами, однако большинство из них являются универсальными и не ориентированы непосредственно на учебный процесс.

Разрабатываемый проект предлагает упрощенный интерфейс, содержащий основные функции, необходимые студенту: создание задач, сроки, предметы, приоритеты, статусы, поиск и фильтрацию.

Проект не ставит целью заменить крупные сервисы управления задачами. Его задача — реализовать простой и понятный инструмент для планирования учебной деятельности.
