# Тестирование проекта «Планировщик учебных задач»

Дата тестирования: 21.10.2026  
Среда: Microsoft Edge / Windows 10

## Методика тестирования

Используется ручное функциональное тестирование.

Для каждого теста выполняется определённое действие, после чего фактический результат сравнивается с ожидаемым.

Статус PASS означает, что приложение работает согласно требованиям.
Статус FAIL означает наличие ошибки.

---

## T-01 — Создание новой задачи

Тип: основной сценарий.

Действия:
1. Нажать «Новая задача».
2. Ввести название «Подготовить презентацию».
3. Указать предмет «Программирование».
4. Выбрать срок выполнения.
5. Установить высокий приоритет.
6. Сохранить задачу.

Ожидаемый результат:
Новая задача появляется в общем списке.

Фактический результат:
Задача появилась в списке.

Статус: PASS

---

## T-02 — Редактирование задачи

Тип: основной сценарий.

Действия:
1. Выбрать существующую задачу.
2. Нажать «Изменить».
3. Изменить название или приоритет.
4. Сохранить изменения.

Ожидаемый результат:
Изменённые данные отображаются в карточке задачи.

Фактический результат:
Данные задачи успешно изменились.

Статус: PASS

---

## T-03 — Выполнение задачи

Тип: основной сценарий.

Действия:
1. Выбрать невыполненную задачу.
2. Нажать «Выполнено».

Ожидаемый результат:
Задача получает статус «Выполнено», а счётчик выполненных задач увеличивается.

Фактический результат:
Статус и счётчик изменились.

Статус: PASS

---

## T-04 — Удаление задачи

Тип: основной сценарий.

Действия:
1. Выбрать существующую задачу.
2. Нажать «Удалить».
3. Подтвердить удаление.

Ожидаемый результат:
Задача исчезает из списка, а общее количество задач уменьшается.

Фактический результат:
Задача была удалена.

Статус: PASS

---

## T-05 — Пустое название

Тип: ошибочный ввод.

Действия:
1. Открыть создание новой задачи.
2. Не вводить название.
3. Заполнить остальные поля.
4. Попытаться сохранить.

Ожидаемый результат:
Приложение не создаёт задачу и сообщает о необходимости заполнить название.

Фактический результат:
Задача не создана, некорректный ввод отклонён.

Статус: PASS

---

## T-06 — Не указан предмет

Тип: ошибочный ввод.

Действия:
1. Открыть создание задачи.
2. Ввести название.
3. Оставить поле предмета пустым.
4. Попытаться сохранить.

Ожидаемый результат:
Задача не создаётся.

Фактический результат:
Приложение не позволило создать некорректную задачу.

Статус: PASS

---

## T-07 — Поиск с отсутствующим результатом

Тип: граничный случай.

Действия:
1. В строку поиска ввести текст, которого нет ни в одной задаче.

Ожидаемый результат:
Список задач становится пустым или приложение сообщает, что подходящих задач нет.

Фактический результат:
Подходящие задачи не отображаются.

Статус: PASS

---

## T-08 — Просроченная задача

Тип: граничный случай.

Действия:
1. Создать невыполненную задачу.
2. Установить срок раньше текущей даты.

Ожидаемый результат:
Приложение определяет задачу как просроченную.

Фактический результат:
Задача отображается как просроченная.

Статус: PASS
