9. Контрольные вопросы и ответы
1. Что такое аутентификация?

Аутентификация — это процесс проверки личности пользователя с помощью логина и пароля или других способов подтверждения личности.

2. Чем отличается аутентификация от авторизации?

Аутентификация подтверждает, кто пользователь, а авторизация определяет, какие действия ему разрешено выполнять.

3. Для чего нужна регистрация пользователей?

Регистрация позволяет создавать новые учётные записи, сохранять данные пользователей и предоставлять им доступ к системе.

4. Что такое пользовательская сессия?

Сессия — это механизм хранения информации о текущем пользователе, позволяющий системе распознавать его при переходе между страницами.

5. Для чего используется LocalStorage?

LocalStorage используется для хранения данных в браузере. В разработанном приложении он сохраняет информацию о пользователях и заявках.

6. Для чего используется SessionStorage?

SessionStorage хранит информацию о текущем сеансе пользователя в браузере и очищается при закрытии вкладки или окна браузера.

7. Что означает HTTP-статус 401?

Код 401 означает, что пользователь не прошёл авторизацию и должен войти в систему для получения доступа.

8. Что означает HTTP-статус 403?

Код 403 означает, что сервер понял запрос пользователя, но запрещает доступ к запрашиваемому ресурсу из-за отсутствия необходимых прав.

9. Чем отличаются ошибки 401 и 403?

401 означает отсутствие подтверждённой авторизации, а 403 означает отсутствие разрешения на доступ к определённому ресурсу.

10. Почему пользователь должен видеть только собственные заявки?

Это необходимо для защиты конфиденциальности данных и предотвращения доступа к информации других пользователей.

11. Как реализуется проверка владельца заявки?

В приложении каждой заявке присваивается идентификатор пользователя. При просмотре заявки JavaScript сравнивает идентификатор владельца с идентификатором текущего пользователя.

12. Для чего используется JavaScript в разработанном приложении?

JavaScript отвечает за регистрацию, авторизацию, создание заявок, отображение информации, проверку доступа и обработку ошибок.

13. Какую роль выполняет HTML?

HTML формирует структуру веб-страницы: формы авторизации, регистрации, личный кабинет и список заявок.

14. Для чего используется CSS?

CSS отвечает за внешний вид приложения: цвета, шрифты, расположение элементов, кнопки и адаптацию под мобильные устройства.

15. Для чего необходим выход из системы?

Выход завершает текущий пользовательский сеанс и предотвращает дальнейшее использование личного кабинета без повторной авторизации.

16. Что произойдёт при попытке открыть заявку другого пользователя?

Приложение проверит идентификатор владельца заявки и отобразит сообщение «403 — Доступ запрещён», если заявка принадлежит другому пользователю.

17. Какие способы хранения данных используются в приложении?

Используются LocalStorage для хранения пользователей и заявок, а также SessionStorage для хранения информации о текущем пользователе.

18. Почему нельзя полагаться только на проверку доступа в JavaScript?

Потому что пользователь может изменить JavaScript-код или данные браузера. В реальных приложениях проверка прав должна выполняться на сервере.
