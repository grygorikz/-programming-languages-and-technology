16. Для чего используется JavaScript в браузере?
JavaScript используется для того, чтобы сделать веб-страницу интерактивной и динамической.

С его помощью можно:

реагировать на действия пользователя;

изменять текст и содержимое страницы;

выполнять вычисления;

проверять введённые данные;

изменять оформление элементов;

создавать и удалять HTML-элементы.

Например, в нашем проекте JavaScript получает температуру, переводит её и выводит результат на страницу.

17. Чем let отличается от const?
Оба используются для создания переменных.

let позволяет изменить значение:

let age = 20;
age = 21;

const нельзя переназначить:

const name = "Alex";
name = "Bob"; // ошибка

То есть главное отличие: let можно переназначить, const — нельзя.

18. Что такое условный оператор?
Условный оператор позволяет программе проверить условие и выбрать, какой код выполнить.

Например:

if (temperature > 0) {
    console.log("Плюсовая температура");
} else {
    console.log("Нулевая или отрицательная температура");
}

Здесь программа проверяет условие и выбирает один из двух вариантов.

19. Какие циклы есть в JavaScript?
Основные циклы:

for

while

do...while

Также существуют циклы для перебора объектов и массивов:

for...of

for...in

Например:

for (let i = 0; i < 5; i++) {
    console.log(i);
}

20. Что такое функция и параметр функции?
Функция — это отдельный блок кода, который выполняет определённую задачу.

Например:

function sum(a, b) {
    return a + b;
}

a и b — это параметры функции.

Когда мы вызываем:

sum(5, 3);

значения 5 и 3 передаются в параметры a и b.

Функции позволяют не повторять один и тот же код.

21. Что такое DOM?
DOM (Document Object Model) — это представление HTML-документа в виде структуры объектов.

Благодаря DOM JavaScript может обращаться к HTML-элементам и изменять их.

Например, JavaScript может найти кнопку:

const button = document.querySelector("#button");

и изменить её содержимое, стиль или обработать нажатие.

22. Как получить HTML-элемент в JavaScript?
Один из способов:

document.querySelector("#result");

Он ищет элемент по CSS-селектору.

Также можно использовать:

document.getElementById("result");

Например:

const result = document.getElementById("result");

получит элемент:

<p id="result"></p>

23. Чем textContent отличается от value?
textContent используется для получения или изменения текста внутри HTML-элемента.

Например:

<p id="result">Привет</p>

result.textContent = "Здравствуйте";

value обычно используется для значения элементов формы, например <input>.

<input id="temperature">

Получить введённое пользователем значение:

const value = temperature.value;

Проще:

textContent → текст элемента;

value → значение поля формы.

24. Что такое событие?
Событие — это действие или изменение, которое произошло в браузере.

Например:

пользователь нажал кнопку → click;

пользователь что-то ввёл → input;

пользователь изменил выбор → change;

страница загрузилась → load.

JavaScript может реагировать на эти события.

25. Для чего используется addEventListener()?
addEventListener() используется, чтобы назначить реакцию на определённое событие.

Например:

button.addEventListener("click", function() {
    console.log("Кнопка нажата");
});

Это означает:

Когда пользователь нажмёт кнопку, выполнить указанную функцию.

В нашем проекте:

convertButton.addEventListener("click", convertTemperature);

При нажатии кнопки запускается конвертация температуры.

26. Как добавить или удалить CSS-класс через JavaScript?
Для этого используется classList.

Добавить класс:

element.classList.add("active");

Удалить:

element.classList.remove("active");

Переключить класс:

element.classList.toggle("active");

Например:

result.classList.add("success");

JavaScript добавит элементу класс success.

27. Как создать HTML-элемент средствами DOM?
Используется:

document.createElement();

Например:

const item = document.createElement("li");

Создаётся новый <li>.

Чтобы добавить его на страницу:

list.appendChild(item);

Именно этот способ мы использовали для создания истории конвертаций.

28. Как перебрать массив с помощью цикла?
Например, есть массив:

const numbers = [10, 20, 30, 40];

Можно использовать for:

for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i]);
}

numbers.length показывает количество элементов массива.

Также можно использовать for...of:

for (const number of numbers) {
    console.log(number);
}

29. Почему проверка пользовательского ввода важна?
Потому что пользователь может ввести неправильные, пустые или невозможные данные.

Например, в нашем конвертере температура в Кельвинах не может быть меньше 0.

Поэтому мы проверяем:

if (from === "K" && value < 0) {
    result.textContent = "Ошибка";
}

Проверка предотвращает неправильные результаты и ошибки программы.

30. Как разделение HTML и JavaScript улучшает структуру проекта?
HTML отвечает в основном за структуру страницы, а JavaScript — за логику и поведение.

Например:

index.html

<button id="convertButton">Конвертировать</button>

script.js

const button = document.querySelector("#convertButton");

Такой подход делает проект более понятным и удобным для изменения.

Если нужно изменить внешний вид или структуру — работаем с HTML.
Если нужно изменить логику программы — работаем с JavaScript.
